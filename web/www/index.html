    Getting started with CP/M

    CP/M is the operating system most 8-bit business computers ran around 1980, before MS-DOS (which borrowed much of it). A> means it's ready for a command on drive A:. Type a command and press Enter; upper or lower case are the same.

    • Built in: DIR lists files, TYPE README.TXT shows a text file, ERA OLD.TXT erases one, REN NEW.TXT=OLD.TXT renames one. * and ? are wildcards: DIR *.COM.
    • Programs are the .COM files: type the name without .COM. STAT shows free space, PIP COPY.TXT=README.TXT copies a file, DDT is the debugger.
    • The editor needs a file name: ED HELLO.TXT. (Without one, ED just says DISK OR DIRECTORY FULL, a quirk of the original.) At its * prompt, I starts inserting text, ^Z (Ctrl, then Z) stops, B#T shows the whole file, and E saves and quits.
    • A first program: ASM DUMP assembles Digital Research's sample source, LOAD DUMP turns it into DUMP.COM, and DUMP DUMP.COM runs it on itself.
    • Keys: ^C at the prompt restarts CP/M (a "warm boot"); ^S pauses scrolling output and any key resumes it; Backspace erases. Some keys are kept by your browser (Ctrl-W, Ctrl-T, Ctrl-N on Windows and Linux): click Ctrl above the screen, then the letter.
    Adding software, and keeping your work
    • Upload…, or drag files onto the screen, to put them on A:. A .zip is unpacked onto the disk, old DOS-era archives included. Uploading restarts CP/M; if a program is running, the page asks first.
    • The Library has the desktop version's software: Zork, Turbo Pascal, WordStar, MBASIC, dBASE II, compilers and games. To get it all:
      1. Click Library, then Download all (or Download on just the programs you want). Your browser may ask once whether this site may download several files, and to Keep each file from retroarchive.org, which has no secure (HTTPS) address.
      2. Open your Downloads folder, select all the new .zip files, and drop them on the screen together.
      The page puts the right files from each archive on A: (leaving out scanned manuals and the like, as the desktop version does) and installs WordStar for this screen. Each program then shows Installed, and its row's name opens a note on how to use it. The archives aren't hosted here: they come from the sites that preserve them, so mind each program's license. For more software, see where to find CP/M software.
    • Download disk saves drive A: as a .dsk file: that file is your real copy. The disk is also kept in this browser between visits, but browsers clear their storage on their own (Safari after a week without a visit; any browser when space runs low or history is cleared). The status line says when you have changes you haven't downloaded. Upload the .dsk to bring it back.
    • Files lists the disk and downloads single files; Fresh disk there starts over.
    Run it on your own computer

    This page is the same emulator, compiled to WebAssembly. The desktop version runs in a terminal window and adds:

    • A debug monitor: press Ctrl-\ at any moment for breakpoints, single-stepping, disassembly, and the Z80's registers and memory.
    • Real files: disks are .dsk files on your computer, written back when you quit, with nothing a browser can clear. The ones this page downloads work there.
    • More drives: up to 16, A: to P:, and host files loaded straight onto a disk from the command line.
    • A ready-made library: make setup downloads classic software (Zork, Turbo Pascal, WordStar set up for your terminal, MBASIC, dBASE II, games) and make play boots with all of it.
    • Your own keyboard: no keys taken by a browser, and --arrows makes the arrow keys move the cursor in WordStar-style editors.
    • More speed and control: native code, an exact clock (--mhz=2 for fast action games), or as fast as your machine goes.

    It needs a Rust toolchain; the quick start goes from download to a running CP/M in four steps.

    About CPeMulator

    CPeMulator emulates a Zilog Z80 processor and a small machine around it, then boots the genuine Digital Research CP/M 2.2, the same code that ran on real hardware, rather than imitating it. The fresh disk holds DRI's own utilities, which DRI's successor allows anyone to redistribute. Everything runs in your browser; nothing you type or upload is sent anywhere.
