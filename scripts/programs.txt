================================================================
            CP/M 2.2  -  PROGRAMS ON THIS DISK
================================================================

Run a program by typing its name at the A> prompt.  BASIC games
(names ending in .BAS) are run with:   MBASIC NAME.BAS

GETTING OUT
  - Each program has its own way to quit (noted below).
  - Ctrl-C returns to A> when the program cooperates.
  - In MBASIC, type  SYSTEM
  - Quit the whole emulator at any time: Ctrl-\

HANDY KEYS
  - Ctrl-S pauses scrolling output; Ctrl-Q (or any key) resumes.
  - Backspace erases; Ctrl-U kills the line; Ctrl-R retypes it.

GOTCHAS (these surprise everyone)
  - Many tools NEED A FILENAME: ED, PIP, ASM, DUMP, LOAD.  Run
    with no name and you get a confusing error.  ED with no file
    even says "DISK OR DIRECTORY FULL" - the disk is fine; ED
    just could not make a work file.  Use  ED FILENAME .
  - Many old programs only accept CAPITAL letters.  Answer their
    Y/N questions with a capital Y or N - or start cpemu --upper.
  - Full-screen programs (WordStar, SuperCalc, the Turbo editor)
    expect a specific terminal.  cpemu emulates an ADM-3A, which
    most are happy with; a few need an INSTALL step first.
  - Action games run at CPU speed.  Too fast?  Restart cpemu
    with  --mhz=2  (or even --mhz=1).

---------------- GAMES & ADVENTURES ----------------------------

ZORK1  ZORK2  ZORK3
   Infocom text adventures.  Type plain English: OPEN MAILBOX,
   READ LEAFLET, GO NORTH, TAKE LAMP.  SAVE and RESTORE work.
   QUIT to leave (it asks you to confirm).
ENCHANTE
   Enchanter - Infocom's fantasy adventure; you play a novice
   magician who collects and casts spells.  Same plain-English
   input as Zork, and SAVE / RESTORE / QUIT all work.
ADVENTUR
   Colossal Cave Adventure.  Answer its opening question to
   start, then explore: GO NORTH, GET LAMP, ENTER, ...
SARGON
   Chess.  Answer the setup questions with a CAPITAL Y or N.
   Enter moves as coordinates, e.g.  E2E4 .
OTHELLO
   Othello (Reversi) against the computer.  Answer its setup
   questions with a CAPITAL Y or N, then play by naming the
   square you want to take.
LADDER
   Arcade climbing game.  Likely TOO FAST - restart --mhz=2.
   Keys: A up, Z down, comma left, period right, Space jump.
PACMAN95
   A Pac-Man-style dungeon chase: eat the coins and grab a
   potion to zap the monsters hunting you.  Arcade speed - if
   it runs too fast, restart cpemu with  --mhz=2 .
CATCHUM
   A faithful Pac-Man clone (full-screen maze).  Menu: 1 for a
   one-player game, L to change level, I for instructions.
   Keys: A/Z up-down, comma/period left-right.  Try --mhz=2.
STAR.BAS
   Star Trek.  Run:  MBASIC STAR.BAS
   Answer "list of commands?" with a CAPITAL Y or it silently
   skips the list.  Commands are numbers (e.g. 4 = fire torpedo).

MORE BASIC GAMES
   Also here, each run with  MBASIC NAME.BAS :  BIGTREK,
   MONOPLY, MONSTER, STARWARS, TVIGAMMO (backgammon), ZILCH
   (a dice game), WORDPUZL.  Most want CAPITAL-letter answers.

---------------- LANGUAGES & COMPILERS -------------------------

MBASIC
   Microsoft BASIC.  Type lines (10 PRINT "HI"), then RUN.
   Ctrl-C stops a running program (back to the Ok prompt);
   LIST shows it, RUN restarts, SYSTEM exits to A>.
TURBO
   Turbo Pascal 3.01a.  Answer N to "include error messages".
   You then get a menu (Edit, Compile, Run...).  The full-screen
   editor needs a good terminal; the menu and Compile/Run work.
MULISP
   muLISP-80 (1980, The Soft Warehouse): a Lisp squeezed onto a
   64K CP/M micro - small by necessity, not by era (it shipped
   to run the muMATH symbolic-algebra system).  Type Lisp at its
   $  prompt, e.g.  (CONS (QUOTE A) (QUOTE B)) .
   Built-ins are CASE-SENSITIVE and UPPER-CASE - (PLUS 2 3) is 5
   but (plus 2 3) is undefined.  Arithmetic is TWO-argument, so
   (PLUS 1 2 3) is 3 (it adds the first two).  An unknown
   function just echoes back, and there is no (+ ...).  Starting
   cpemu --upper lets you type in lower case.  Ctrl-C exits.
CC   (BDS C)
   A real C compiler.  Build a program in three steps:
     CC HELLO.C       compile  ->  HELLO.CRL
     CLINK HELLO      link     ->  HELLO.COM
     HELLO            run it
   Put  #include <STDIO.H>  at the top for printf and friends.
   Also on the disk if you want them: Microsoft FORTRAN-80 (F80)
   and CBASIC (CB80), each compile-then-link like CC.

---------------- PRODUCTIVITY ----------------------------------

DBASE
   dBASE II database.  It asks for today's date - press Return to
   skip.  You get a  .  prompt; try  ? "HELLO" .  Leave with the
   QUIT command (don't just Ctrl-C, or you may lose data).
MP
   Microsoft Multiplan, a spreadsheet.  Full-screen; it drives an
   ADM-3A so it should display.  Commands are the menu along the
   bottom - Quit from there.
SC
   SuperCalc spreadsheet.  Not pre-configured for a terminal in
   this build, so it may not display correctly yet.
WS
   WordStar word processor.  Full-screen; run WINSTALL once to
   set it up for a terminal.  Commands are Ctrl-key combos;
   ^KX saves and exits, ^KQ quits without saving.

---------------- TEXT TOOLS ------------------------------------
SPELL  FILE      Check spelling (Oasis "The Word Plus").  Lists
                 every word not in its dictionary, e.g.
                 SPELL LETTER.TXT .
WORDFREQ  FILE   Count how often each word appears.
WC  FILE         Count lines, words and characters.
   The Word Plus also adds FIND, HUNT, LOOKUP, REVIEW, ANAGRAM,
   DICTSORT and HYPHEN - run one with no filename to see how it
   wants to be called.

---------------- BUILT-IN COMMANDS -----------------------------
These are part of CP/M itself, always available - they are NOT
files on the disk, so they do not appear in  DIR *.COM .  CP/M
2.2 has no HELP command; this file is your guide.

DIR  [pattern]   List files.  DIR  /  DIR *.COM  /  DIR B:
TYPE  FILE       Show a text file.  e.g.  TYPE PROGRAMS.TXT
ERA  pattern     Erase files.  e.g.  ERA *.BAK
REN  NEW=OLD     Rename a file.  e.g.  REN NEW.TXT=OLD.TXT
USER  n          Switch file group 0-15 (same disk, NOT a new
                 drive).  Other groups' files are hidden, not
                 erased; programs only run from their own group.
                 USER 0 is home - go back there to find things.
SAVE  n FILE     Save n 256-byte pages of memory to a file.
A:  B:  ...      Change the current drive (type a letter + colon).

Wildcards: ? = any one character, * = the rest of the name or
type.  So  *.COM  is every .COM file,  A*.*  is names from A.

---------------- UTILITIES (programs on the disk) --------------
Run these by name; most take a FILENAME.

STAT             Free space and file sizes.  STAT *.*
PIP  NEW=OLD     Copy a file.  e.g.  PIP B:=A:FOO.TXT
ED  FILE         Edit a file - NEEDS a filename.  Inside ED:
                 I = insert (type lines), ^Z = stop inserting,
                 E = save and exit.
DDT  FILE        Debugger.  Type  G0  to exit to A>.
ASM  FILE        8080 assembler (expects FILE.ASM).
LOAD  FILE       Turn FILE.HEX into a runnable FILE.COM.
DUMP  FILE       Hex-dump a file.
SUBMIT  FILE     Run a batch of commands from FILE.SUB.

---------------- MORE ON THE DISK ------------------------------
This guide covers the highlights.  DIR lists EVERYTHING - and
there is more to find: extra games (try NEMESIS), small file
tools (XDIR, D, LIST, USQ to un-squeeze), and the rest of the
Word Plus.  Most tools print a usage line if you run them with
no filename, so poke around.
